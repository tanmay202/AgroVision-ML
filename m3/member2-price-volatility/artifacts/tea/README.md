# Tea Model Artifacts

This folder contains baseline model weights, feature configurations, and group mappings for the **Tea** reference baseline.

## Files

1. `tea_price_model.pkl`: Baseline 20-feature XGBoost price regressor.
2. `tea_volatility_model.pkl`: Baseline 19-feature class-balanced XGBoost volatility classifier.
3. `tea_feature_config.json`: Feature specification and metrics.
4. `tea_volatility_config.json`: Volatility thresholds.
5. `tea_group_mappings.json`: Canonical market (13) and variety (4) strings for North Bengal auction markets.
